# MediaNova — GitHub Pages

واجهة عربية/إنجليزية بتصميم Premium، جاهزة للنشر على GitHub Pages.

## النشر
1. أنشئ مستودعًا جديدًا على GitHub باسم `medianova`.
2. ارفع محتويات هذا المجلد إلى جذر المستودع (خصوصًا `index.html`).
3. افتح **Settings → Pages**.
4. اختر **Deploy from a branch** ثم `main` و`/(root)` ثم Save.
5. انتظر رابط الموقع الذي سيظهر في صفحة Pages.

## مهم بخصوص التحميل
GitHub Pages يستضيف ملفات ثابتة فقط؛ لا يشغّل خادم استخراج/معالجة فيديو. الواجهة حاليًا تفتح روابط الوسائط المباشرة التي تسمح خوادمها بذلك، وتعرض توضيحًا عند لصق رابط منصة يحتاج تكاملًا خلفيًا.

لإضافة خدمات منصات، يلزم خادم مستقل (مثل خدمة Node/PHP مستضافة) مع واجهات رسمية أو مزوّد يصرّح بتنزيل المحتوى. لا تضع مفاتيح API أو أسرارًا داخل `index.html` أو مستودع GitHub العام. لا تستخدم الخدمة لتنزيل محتوى خاص أو محمي أو لتجاوز DRM أو قيود المنصة.

## الملفات
- `index.html`: الموقع كاملًا في ملف واحد.

## تكامل Direct
- يقبل روابط ملفات مباشرة بامتدادات الصور والفيديو والصوت وPDF.
- يحاول جلب الملف باستخدام `fetch` ثم يتيح تنزيل Blob مع معاينة الصور والفيديو.
- إذا منع الخادم CORS أو تطلب تسجيل دخول، يعرض سببًا عامًا ويتيح فتح الرابط الأصلي؛ لا يحاول تجاوز قيود الوصول.
- هذا التكامل يعمل من المتصفح فقط ولا يحتاج API key أو سيرفر. نجاحه يتوقف على إعدادات CORS لدى مصدر الملف.
- `README.md`: تعليمات النشر والحدود التقنية.
